# andreolsen.github.io

My personal website, live at [andreolsen.github.io](https://andreolsen.github.io).

Astro, Tailwind and a little SCSS. Every push to `main` builds and deploys to
GitHub Pages.

## Running it

Uses [Bun](https://bun.sh), and needs Node 22.12 or newer (see `.nvmrc`).

```bash
bun install
bun run dev      # http://localhost:4321
bun run build    # output in dist/
```
